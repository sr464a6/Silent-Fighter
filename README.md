## 🕹️ Controls & Features

<details>
<summary><b>⌨️ Click to View Controls</b></summary>

| Key | Action |
| :---: | :--- |
| <kbd>A</kbd> | Move Left |
| <kbd>D</kbd> | Move Right |
| <kbd>W</kbd> | Jump |
| <kbd>J</kbd> | Normal Attack |
| <kbd>K</kbd> | Power Attack |
| <kbd>R</kbd> | Restart Game |
| <kbd>ESC</kbd> | Exit Game |

</details>

<details>
<summary><b>❤️ Health & Score System</b></summary>

- **Fighters:** Silent Fighter vs The Corruptor (100 HP each)
- **Objective:** Reduce the enemy's HP to zero to win.
- **Score:** Earn points by dealing damage and get a `+1000` bonus upon winning.

</details>

<details>
<summary><b>🛠️ Tech Stack</b></summary>

- Python & Pygame
- Object-Oriented Programming (OOP)
- Sprite Animation & Collision Detection
- Enemy AI & Game State Management

</details>
